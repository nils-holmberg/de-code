Quarto markdown and notebooks

One source file holds the text, the code, and the output it produced. Quarto renders it to a report, a slide deck, or a website, and runs Python and R side by side, so the analysis and the writing about it stay in step.

Book this session All education

What the session covers

Markdown that computes

Write in plain markdown, drop in code cells, and render the document so every figure and number comes from the code that produced it.

Python and R together

Run both languages from the same document, pick whichever suits the task, and share data between cells without leaving the file.

Notebooks to publication

Take an existing Jupyter notebook and publish it as HTML, slides, or PDF, with output that can be rebuilt from source at any time.

A document you can re-run is a document you can trust. Reproducible reporting is a practical skill, not a specialist one.

Bring it to your organization

Sessions run on site or over video meeting, for teams new to Quarto as well as groups already writing notebooks who want them reproducible and publishable.
